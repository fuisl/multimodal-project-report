\subsection{Model Building and Training}
\label{sec:model-building}

We implemented and evaluated three distinct approaches: Retrieval-Augmented Generation (RAG), model fine-tuning, and a hybrid combination. This section details the architecture, training pipeline, and technical implementation of each method.


\subsubsection{RAG (Retrieval-Augmented Generation) Pipeline}
\label{sec:rag-pipeline}

\paragraph{Architecture Overview}
The RAG system enhances large multimodal models with external medical knowledge through dynamic retrieval:

\begin{enumerate}
    \item \textbf{Retriever Component:}
    \begin{itemize}
        \item Embedding Model: [e.g., BioBERT, PubMedBERT, or domain-specific encoder]
        \item Vector Store: [e.g., FAISS, Pinecone, ChromaDB]
        \item Retrieval Strategy: [e.g., dense retrieval, hybrid (dense + sparse)]
        \item Top-K Selection: [e.g., retrieve top 5-10 most relevant chunks]
    \end{itemize}
    
    \item \textbf{Ranker Component (Optional):}
    \begin{itemize}
        \item Re-ranking Model: [e.g., cross-encoder for relevance scoring]
        \item Purpose: Refine retrieval results for higher precision
    \end{itemize}
    
    \item \textbf{Generator Component:}
    \begin{itemize}
        \item Base LMM: [e.g., GPT-4V, LLaVA, Gemini, Claude]
        \item Context Window: [e.g., 32K tokens]
        \item Input Format: Retrieved context + patient data + images
    \end{itemize}
\end{enumerate}

\paragraph{RAG Implementation Pipeline}
\begin{enumerate}
    \item \textbf{Query Processing:}
    \begin{itemize}
        \item Extract key medical terms from patient presentation
        \item Generate query embeddings using retriever model
    \end{itemize}
    
    \item \textbf{Retrieval Phase:}
    \begin{itemize}
        \item Similarity search in vector database
        \item Retrieve top-K relevant medical knowledge chunks
        \item Apply metadata filtering (disease category, source credibility)
    \end{itemize}
    
    \item \textbf{Context Construction:}
    \begin{itemize}
        \item Combine retrieved knowledge with patient data
        \item Format multimodal inputs (text + images)
        \item Construct prompt template with clinical reasoning instructions
    \end{itemize}
    
    \item \textbf{Generation Phase:}
    \begin{itemize}
        \item Feed enriched context to LMM
        \item Generate diagnostic predictions with reasoning
        \item Post-process outputs for structured format
    \end{itemize}
\end{enumerate}

\subsubsection{Hybrid Combination Approach}
\label{sec:hybrid-approach}

The hybrid approach integrates the strengths of both RAG and fine-tuning:

\paragraph{Architecture}
\begin{enumerate}
    \item \textbf{Base:} Fine-tuned multimodal model with domain-specific adaptations
    \item \textbf{Enhancement:} RAG layer for dynamic knowledge augmentation
    \item \textbf{Integration Strategy:}
    \begin{itemize}
        \item \textbf{Option 1 - Sequential:} RAG retrieves context $\rightarrow$ fine-tuned model processes
        \item \textbf{Option 2 - Parallel:} Both systems generate predictions $\rightarrow$ ensemble/fusion
        \item \textbf{Option 3 - Adaptive:} Model decides when to invoke RAG based on confidence
    \end{itemize}
\end{enumerate}
